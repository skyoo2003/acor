## [v1.7.0](https://github.com/skyoo2003/acor/releases/tag/v1.7.0) - 2026-10-02

### Added

* Added a V3 benchmark dashboard and validation reports covering Redis and Valkey performance at up to one million keywords. ([#256](https://github.com/skyoo2003/acor/issues/256))
* Added scrape-time, collection-labeled V3 Prometheus metrics and observability-aware HTTP and gRPC server constructors. ([#270](https://github.com/skyoo2003/acor/issues/270))
* Opt-in V3 sharded storage and complete-generation local search, snapshot-safe Reshard transitions, shard refresh diagnostics, and a strict same-environment scale regression schema. Legacy V3 remains the default; controlled large-scale and live multi-node Cluster qualification are still pending. ([#271](https://github.com/skyoo2003/acor/issues/271))
* Added HTTP and gRPC V3 search, bounded text transformations, expected-version writes, version barriers, and commit-receipt recovery in the experimental server module. ([#269](https://github.com/skyoo2003/acor/issues/269))

### Changed

* Optimized V3 search scanning and batched Redis staging to reduce work for common ASCII inputs and multi-bucket updates. ([#259](https://github.com/skyoo2003/acor/issues/259))
* V3 now serves one immutable engine for every version, removing the experimental two-automaton overlay while retaining DeltaSearch option and status compatibility. ([#260](https://github.com/skyoo2003/acor/issues/260))

### Fixed

* Versioned rewrite endpoints now enforce server-side match, candidate, and output limits and report malformed mask values as client errors. ([#269](https://github.com/skyoo2003/acor/issues/269))
* Release container bases now match their target architecture, preserving usable system tools on AMD64 and ARM64. ([#272](https://github.com/skyoo2003/acor/issues/272))
* V3 health now recovers after transient Redis errors without a dictionary update, and malformed HTTP and gRPC requests return client errors instead of server errors. ([#272](https://github.com/skyoo2003/acor/issues/272))

### Documentation

* Changelog entries are now capped at one sentence, two at the very most, enforced by `block: false` and `maxLength: 400` in `.changie.yaml` and documented in CONTRIBUTING.md, RELEASE.md, and the PR template. All 174 existing entries were condensed to the same shape, preserving every issue number, kind, date, and measured figure. ([#250](https://github.com/skyoo2003/acor/issues/250))
* Condensed the documentation site and removed duplicated pages: `preset-engine`, `redis-backed-engine`, and `reference/api` each repeated a Quick Start, preset table, or API surface, and eight pages carried hand-written nav footers the theme already renders. Also fixed a dead `guides/presets/` link, a disagreeing CLI command count, and a missing `FindSetContext` entry. ([#249](https://github.com/skyoo2003/acor/issues/249))
